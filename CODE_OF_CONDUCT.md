# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep feedback about the work and not the person, and do not harass anyone.

Unacceptable behaviour can be reported to the maintainers by opening a private security advisory
(<https://github.com/danielingemar/lumen/security/advisories/new>) or by contacting the repository owner on GitHub.
Maintainers may remove comments, issues or contributions, and block people who do not follow this code.
